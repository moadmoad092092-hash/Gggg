قفزة الظل — نموذج لعبة باركور ثلاثية الأبعاد للويب
==================================================

المميزات:
- عالم ثلاثي الأبعاد مبني باستخدام Three.js.
- شخصية مكعبة قابلة للحركة.
- عصا افتراضية للمشي على الهاتف.
- زر قفز.
- تدوير كاميرا الشخص الثالث بسحب الشاشة.
- لوحة تقدم ومؤقت وبوابة نهاية.
- تحكم لوحة المفاتيح: WASD أو الأسهم، و Space للقفز.
- لا يحتاج API أو حسابًا أو قاعدة بيانات.

مهم:
يستخدم المشروع Three.js من CDN، لذلك يلزم اتصال بالإنترنت لتحميل مكتبة 3D.
شغّل المشروع عبر خادم محلي أو استضفه على خدمة استضافة صفحات ثابتة. فتح index.html مباشرة
قد لا يعمل في بعض المتصفحات لأن game.js يستخدم JavaScript modules.

أسهل طريقة من الهاتف:
1. فك ضغط ZIP.
2. ارفع الملفات الثلاثة (index.html وstyle.css وgame.js) إلى مشروع HTML على منصة تستضيف مواقع ثابتة.
3. افتح رابط المعاينة في المتصفح.
4. على الهاتف: اسحب عصا الحركة يسار الشاشة، اسحب المنطقة الوسطى لتدوير الكاميرا، واضغط زر قفز.
5. على الكمبيوتر: WASD أو الأسهم للحركة وSpace للقفز.

هذه نسخة أولية فردية وليست لعبة Roblox رسمية. اللعب الجماعي وحفظ الحسابات وإنشاء خرائط اللاعبين غير مضافة بعد.
